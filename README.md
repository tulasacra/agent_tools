# agent_tools

Two console commands for Cursor, GitHub Copilot, and Codex.

| File | Command | What it does |
| --- | --- | --- |
| `agent_launch` | `aa` | Pick 1 cursor, 2 copilot, or 3 codex, then launch it |
| `agent_usage` | `au` | Usage rows: `34% \| 5 days \| 1.11.26` |

Install:

```bash
ln -sfn "$PWD/agent_launch" ~/.local/bin/aa
ln -sfn "$PWD/agent_usage" ~/.local/bin/au
```
